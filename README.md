# 🤖 WhatsApp Personal AI Agent (১০০% ফ্রি)

Google Gemini AI দিয়ে চালিত একটি সম্পূর্ণ ফ্রি স্বয়ংক্রিয় WhatsApp এআই অ্যাসিস্ট্যান্ট। এটি আপনার হয়ে ইনকামিং মেসেজের স্বাভাবিক ও বুদ্ধিমান উত্তর দেবে।

---

## 🌟 সুবিধাসমূহ
- **১০০% ফ্রি:** কোনো সাবস্ক্রিপশন ফি বা পেইড সার্ভার নেই।
- **Gemini 1.5 Flash:** দ্রুত ও অত্যন্ত নির্ভুল এআই রেসপন্স (বাংলা, ইংরেজি ও বাংলিশ যেকোনো ভাষায় স্বাচ্ছন্দ্যে কথা বলে)।
- **Conversation Memory:** আগের কথার সূত্র ধরে পরবর্তী কথার উত্তর দেয়।
- **রিমোট কন্ট্রোল (Active/Inactive Mode):** আপনার নিজের ফোন থেকেই WhatsApp মেসেজ দিয়ে এজেন্ট অন বা অফ করতে পারবেন।
- **নিরাপদ সেশন:** একবার QR কোড স্ক্যান করলেই সেশন লোকাল কম্পিউটারে সেভ থাকে, বারবার লগইন করতে হয় না।

---

## 🛠️ সেটআপ নির্দেশিকা

### ধাপ ১: ফ্রি Gemini API Key নিন
1. [Google AI Studio](https://aistudio.google.com/) লিংকে যান।
2. আপনার Google অ্যাকাউন্ট দিয়ে লগইন করুন।
3. **Get API Key** বাটনে ক্লিক করে একটি ফ্রি কী তৈরি করে কপি করুন।

### ধাপ ২: `.env` ফাইল কনফিগার করুন
প্রোজেক্ট ফোল্ডারে একটি `.env` ফাইল তৈরি করুন (বা `.env.example` কে রিনেম করে `.env` করুন) এবং আপনার এপিআই কী ও নাম বসান:
```env
GEMINI_API_KEY=AIzaSy...আপনার_এপিআই_কী
OWNER_NAME="আপনার নাম"
AGENT_NAME="Personal AI Assistant"
AUTO_REPLY_ACTIVE=true
REPLY_TO_GROUPS=false
```

### ধাপ ৩: এজেন্ট রান করুন
টার্মিনাল বা কমান্ড প্রম্পটে লিখুন:
```bash
npm start
```
(অথবা `node index.js`)

টার্মিনালে একটি **QR কোড** আসবে। আপনার মোবাইল থেকে WhatsApp ওপেন করে **Linked Devices > Link a Device** দিয়ে কোডটি স্ক্যান করে নিন।

## 📱 আপনার ফোন থেকে রিমোট কন্ট্রোল কমান্ড
আপনি যেকোনো সময় নিজের হোয়াটসঅ্যাপ থেকেই নিজের নম্বরে বা সেভড মেসেজে নিচের কমান্ড পাঠিয়ে এজেন্ট নিয়ন্ত্রণ করতে পারবেন:

| কমান্ড | কাজ |
|---|---|
| `!bot on` | এজেন্ট চালু হবে এবং ইনকামিং মেসেজের উত্তর দেওয়া শুরু করবে |
| `!bot off` | এজেন্ট স্লিপে চলে যাবে (অটো-রিপ্লাই বন্ধ থাকবে) |
| `!bot status` | এজেন্ট কতক্ষণ ধরে চলছে এবং কয়টি রিপ্লাই দিয়েছে তা দেখাবে |
| `!bot clear` | সংশ্লিষ্ট চ্যাটের মেমোরি রিসেট করবে |
| `!bot help` | কমান্ড তালিকা দেখাবে |
